## 4 代码要求

### 4.1 必须做到

- 有**基线对照**（传统方法 vs 本文方法）与**定量指标**；
- 代码量小，不超过20个cell，每个cell内容精炼；
- 有**参数扫描**（至少 2 个关键参数）并给出取值依据；
- 每个关键实现配**可运行的断言式自检**（见 4.3）；
- 中文显示正常，无缺字形告警；[自动]
- 随机种子固定，结果可复现。

### 4.2 禁止

- 禁止编造数据、编造参考文献、编造作者信息；
- 结论必须由实测数据支撑，**未能验证的结论不得写入**；
- 实验不理想时**如实报告**，不得只报喜。

### 4.3 关键实现必须带自检

自检要在 Notebook 里**直接打印结论**，且能被一眼判定。踩过坑的实现尤其要自检：

| 实现 | 必查内容 |
| --- | --- |
| 频域滤波 | 滤波器原点与频谱索引约定一致（`fftfreq` 未移位 ⇒ `fft2` 不移位，`H[0,0]=1`） |
| 多尺度匹配 | **只缩放一侧**：只缩模板（图不动）或只缩图像（模板不动），两者数学**等价**；两边同时缩则尺度比不变，必然失败 |
| 模板金字塔 | 必须含**放大**变体，否则无法检出比模板大的目标 |
| NMS | 构造重叠框，验证只保留 1 个最高分框 |
| 坐标映射 | 响应图尺寸为 `(H-h+1, W-w+1)`，其位置直接对应模板左上角 |

> **多尺度自检范式**（实测：只缩模板 = 1.0000，两边同缩 = 0.2983）
>
> ```python
> pk_ok   = ncc_match(src, resize_template(tpl, 0.5))[1]        # 只缩模板
> pk_bad  = ncc_match(resize(src, 0.5), resize_template(tpl, 0.5))[1]  # 两边同缩
> assert pk_ok > 0.9 and pk_bad < 0.5
> ```

### 6.2 公式：用 Word 原生公式（OMML），可编辑

**python-docx 不支持数学公式**，直接删 LaTeX 反斜杠会得到 `frac{sum{...}}` 这种残骸。
做法是把 LaTeX 转成 **OMML**（Office Math Markup Language）插入，Word 中即为**原生可编辑公式**。

**两条致命约束**（违反任一条，Word 会报"文件可能已经损坏"并拒绝打开）：

| # | 约束 | 错误写法 | 正确写法 |
| --- | --- | --- | --- |
| 1 | **分式的分子/分母必须用专用标签** | `m:fPr, m:e, m:e` | **`m:fPr, m:num, m:den`** |
| 2 | **显示公式必须用 `m:oMathPara` 包裹** | `<m:oMath>` 直接挂 `w:p` | **`<m:oMathPara><m:oMath>…</m:oMath></m:oMathPara>`** |

反之**行内公式必须用裸 `<m:oMath>`**（不加包裹），两者不可混用。

实现要点：

| 项目 | 要求 |
| --- | --- |
| 转换器 | `_tools\omml.py`（LaTeX → OMML），由 `build_docx_md.py` 调用 |
| 公式编号排版 | **用两个制表位**：`[居中制表位=半版心] 公式 [右制表位=全版心] （编号）`。<br>只把段落设为居中会让编号紧贴公式，**必须**改为左对齐＋双制表位 |
| 其他结构 | 根号 `m:radPr/m:deg/m:e`；大型运算符 `m:naryPr/m:sub/m:sup/m:e`；重音 `m:accPr/m:e`；定界符 `m:dPr/m:e` |
| 属性元素 | 各结构的 `*Pr` 须排最前；上下标结构须带 `m:sSubPr`/`m:sSupPr` 等 |
| 数学 run | `m:r` 内建议带 `w:rPr`＋`w:rFonts w:ascii="Cambria Math"` |
| 命名空间 | `xmlns:m` 须在 `<w:document>` 根元素声明；**禁止**调用 `lxml.cleanup_namespaces`（会删掉 `mc:Ignorable` 引用的扩展命名空间，导致 Word 拒开） |
| 兜底方案 | 若 OMML 出问题，可 `set DOCX_MATH=img` 切到图片渲染（`mathimg.py`）。但图片**字号与正文不易匹配**，非必要不用 |
| 事后修复 | 若已有 docx 的编号没右对齐，用 `_tools\fix_eq_number.py <章节>` 就地修正，不必重新生成 |

**校验公式编号是否合格**（不依赖 Word，快速）：

```python
# 显示公式段落应满足：段落左对齐、含 居中+右对齐 两个制表位、编号文本以 \t 开头
ts = [(t.position.cm, str(t.alignment)) for t in para.paragraph_format.tab_stops]
assert any("CENTER" in a for _, a in ts) and any("RIGHT" in a for _, a in ts)
assert text.startswith("\t")
```

**排查手法**（下次遇到"Word 打不开"照此做）：

1. 用 Word COM 打开一次，读**真实错误码**——`文件可能已经损坏`=结构问题；`命令失败(36966)`=文件被占用。
2. 把**每个公式单独建文档**让 Word 判定，再**二分**定位到具体公式。
3. 要权威写法，就让 **Word 自己生成**：写入线性格式 `a^2/b`，调用 `doc.OMaths(1).BuildUp()`，解包看它生成的 OMML。

## 7 交付前自检

```powershell
# 1) Markdown 书写规范（必须 0 处问题）
python D:\workspace\Jupyter_WorkSpace\DIP\_tools\check_md.py

# 2) 交付物总校验（不通过项必须为 0）
python D:\workspace\Jupyter_WorkSpace\DIP\_tools\verify.py 0202
```

`verify.py` 覆盖 7 类共 30+ 项，其中**三项是硬性判据**：

| 硬性判据 | 说明 |
| --- | --- |
| **Word 实际打开成功** | 调用 Word COM 真实打开一次。这是"文档能否使用"的**唯一可信判据** |
| 分式用 `m:num`/`m:den` | 分式数 == 分子数 == 分母数（写成 `m:e` 会让 Word 拒开） |
| 显示公式用 `m:oMathPara` 包裹 | `oMathPara` 数 ≥ 显示公式数 |
| Markdown 块结构合规 | `check_md.py` 报 0 处 |

**判据排除表**（以下均**不能**证明 Word 能打开）：

| 中间层判据 | 为何不可信 |
| --- | --- |
| zip 完整性 | 只验证压缩包未损坏 |
| lxml 能解析 | 只验证 XML 语法 |
| python-docx 能读 | 不做 OOXML Schema 校验 |
| 自写 Schema 校验 | 覆盖不到 Word 的私有约束 |

**注意**：若目标 Word 文件正被手动打开，自动化实例会报 `命令失败`（错误号 36966）——
这不是文件损坏。判定前先关闭 Word，或把文件复制到另一路径再测。

## 8 已知易误判点（避坑）

| # | 坑 | 正确做法 |
| --- | --- | --- |
| 8.1 | 用 `df["col"]` 式的错位统计导致误报 | 校验口径**必须与生成口径一致**（如表格数：都用"表头行+分隔行"判定） |
| 8.2 | 从正文第一次出现"参考文献"处开始数文献 | 从**最后一次**出现处切分 |
| 8.3 | 统计表格数值时把公式里的数字算进去 | 先**整块剔除** `$$...$$` 与 `$...$`（含以 `\|` 开头的绝对值行） |
| 8.4 | 用错误的方式"读"文件去诊断排版 | 排版问题**只看 nbconvert 渲染结果** |
| 8.5 | Word 锁文件 `~$xxx.docx` 干扰 | 生成前**关闭 Word**；`glob` 时过滤 `~$` 开头 |
| 8.6 | Word 自动化进程残留占用文件 | 结论：**不要用 `rmdir /s` 删目录**，删前确认路径、优先可恢复方式 |
| 8.7 | PowerShell 内联多行 Python 引号被吞 | 写成 `.py` 文件执行；输出不要拼 `\|` |
| 8.8 | f-string 内含反斜杠报语法错 | 把正则提到 f-string 外，或改用脚本文件 |
| 8.9 | 写日志时 `_scratch\` 不存在 | 先 `LOG.parent.mkdir(parents=True, exist_ok=True)` |
| 8.10 | 句中误用 `$$K$$` 当行内公式 | 行内用**单个** `$`；`$$` 必须独占一行。`verify.py` 与生成器均只认"整行 `$$`"为块定界 |
| 8.11 | Word 打开失败就断定文件损坏 | 先看错误码：`文件可能已经损坏`=结构问题；`命令失败(36966)`=文件被占用 |
